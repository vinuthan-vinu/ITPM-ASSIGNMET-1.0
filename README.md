https://www.pixelssuite.com/

## Automated Scenario

The automated scenario follows the provided "Automation Steps - Option 2" instructions.

- Feature: Image format conversion
- Page URL: `https://www.pixelssuite.com/convert-to-png`
- Input: PNG file
- Check: Preview is displayed after upload

## Setup

Open a terminal in the `test_automation_ui` folder:

```bash
cd test_automation_ui
pip install -U pip
pip install playwright openpyxl
playwright install
```

## Run

```bash
python image_preview_test.py --url "https://www.pixelssuite.com/convert-to-png" --slow-mo-ms 2000
```

For a headless run:

```bash
python image_preview_test.py --url "https://www.pixelssuite.com/convert-to-png" --headless
```

After the run, check:

- `test_automation_ui/execution_results.csv`
- `test_automation_ui/results/preview_pass.png`
